# Demo script

`uv run chaosusers demo --no-open` replays the committed scripted cassette. The banner says SCRIPTED DEMO because no live model was recorded yet. Cost is $0.

The gauntlet run uses seed 33, 6 personas, 2 repeats, and 5 turns. It shows one success, silent failures, a forbidden refund, people who give up, and one turn-cap. The panel run shows 8 personas stuck on the hero of the sample landing page.

Replace the cassettes with a real recording before a public launch. Do not edit the jsonl by hand.
